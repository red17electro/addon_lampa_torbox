# TorBox Lampa Plugin

[English](README.md) | **Українська**

Плагін для [Lampa](https://lampa.mx), який додає перегляд торрентів через [TorBox.app](https://torbox.app) просто з картки фільму/серіалу.

Поточна версія: **51.2.15**

## Можливості

- 🔍 Пошук торрентів через публічні парсери (MaxVol, Jacred) з failover і автоматичним cooldown для недоступних
- ⚡ Перевірка кешу TorBox: одразу видно, які торренти кешовані (⚡), а які ні (☁️), плюс перемикач «лише кешовані»
- 🎛 Фільтри (якість, тип відео, озвучення, мова аудіо, кодеки, трекер) і сортування (сіди, розмір, дата)
- 📺 Серіали: список епізодів, відстеження переглянутих серій, панель «Продовжити перегляд»
- 🎬 Фільми: список файлів з автовибором найкращого (найбільший, без sample/trailer)
- ⬇ Прямі посилання на завантаження через TorBox з передачею системі та копіюванням у буфер як запасний варіант
- 🕹 Повна навігація з пульта на TV
- 🌍 Мови інтерфейсу: українська, англійська, російська

## Встановлення

1. Відкрийте Lampa: `Налаштування` → `Плагіни` → `Додати плагін`.
2. Вставте URL:
   ```
   https://slonce70.github.io/addon_lampa_torbox/torbox-lampa-plugin.js
   ```
3. Натисніть `Enter` і перезапустіть Lampa.

## Налаштування

`Налаштування` → `TorBox`:

- **URL CORS-проксі** — проксі для TorBox і початкових запитів до публічних парсерів. Якщо запит до парсера через проксі не вдався, плагін повторює пошук напряму без API-ключа та cookies. Еталонний проксі вшито за замовчуванням; URL, який ви введете, завжди має пріоритет. Увага: проксі бачить ваш API-ключ, тож використовуйте лише той, якому довіряєте (наполегливо радимо HTTPS).
- **API-ключ** — ваш ключ TorBox. Введіть власний ключ; вбудованого API-ключа немає.

Розширені параметри (пріоритет якості/аудіо/кодеків, виключення трекерів, опитування статусу, відеорозширення, користувацькі парсери, debug і діагностика) приховані з інтерфейсу та працюють на розумних значеннях за замовчуванням. За потреби їх можна перевизначити через відповідні ключі `torbox_*` у `localStorage`.

### CORS-проксі (Cloudflare Worker)

Вихідний код еталонного CORS-проксі лежить у [proxy/cloudflare-worker.js](proxy/cloudflare-worker.js). Він проксіює запити лише до API TorBox і публічних парсерів, додає API-ключ на боці сервера тільки для `api.torbox.app` і повертає CORS-заголовки на кожну відповідь (включно з помилками). Щоб задеплоїти власну копію:

```bash
cd proxy
npx wrangler deploy
```

Якщо використовуєте користувацькі парсери — додайте їхні домени в `ALLOWED_HOSTS` у воркері.

## Керування з пульта (TV)

- Навігація побудована на стандартних правилах Lampa: елементи з `.selector` і події `hover:focus` / `hover:enter`.
- `Right` зі списку торрентів одразу відкриває фільтри.
- Перемикач `⚡/☁️` вбудований у панель фільтрів і не ламає фокус.
- У списку файлів: `OK` на файлі запускає перегляд, `Right` переводить фокус на кнопку завантаження `⬇`.

## Розробка

### Швидкі перевірки (локально)

```bash
npm ci
npm run build:legacy
npm run validate
npm run test:unit
npx playwright install chromium
npm run test:e2e
```

Після змін вихідного коду закомітьте згенерований legacy-файл. Валідація
перевіряє синтаксис ES2018 та відхиляє відсутню або застарілу збірку. CI
перевіряє код і тести на кожен push до main та pull request. Браузерні тести
запускають обидві збірки в сучасному Chromium; перевірка на TV ще потрібна.

### Ручний чек-лист на TV

- Відкрити картку фільму/серіалу → зайти в TorBox.
- Поки йде завантаження: `Right/Left/Up/Down/Back` не ламають екран.
- Список торрентів: `Up/Down` гортає, фокус не зникає.
- `Right` зі списку → фільтри відкриваються одразу.
- За наявності «Продовжити перегляд»: `Up` з першого елемента списку → «Продовжити перегляд», далі `Up` → пошук/фільтри.
- Перемикач `⚡/☁️`: `OK` перемикає режим, список оновлюється, фокус не стрибає.
- `OK` на торренті відкриває список відеофайлів (фільми, однофайлові релізи та серіали).
- У списку файлів: `OK` на файлі запускає перегляд; `Right` з файлу → кнопка `⬇`; `OK` на `⬇` отримує пряме посилання TorBox, передає його системі для завантаження/зовнішнього відкриття та копіює посилання як запасний варіант; `Left` повертає на файл; `Back` повертає до списку торрентів.

## Діагностика

- Увімкніть debug-режим (`localStorage.torbox_debug = '1'`) і дивіться `Console` (повідомлення з префіксом `[TorBox]`).
- Якщо на TV «фільтр не відкривається», майже завжди причина у фокусі (не на тій кнопці) або в тому, що елемент не потрапив до колекції навігації.

## Відмова від відповідальності

Плагін не зберігає та не розповсюджує жодного контенту. Він лише інтегрує API TorBox і публічні торрент-індексатори в інтерфейс Lampa. Ви самі відповідаєте за те, як використовуєте його, та за дотримання законів своєї країни.
